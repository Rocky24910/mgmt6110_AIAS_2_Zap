My Agent Card | School Mail Sentinel | finished 20 October 2026, 19:55 SGT

1. The job: Detect matching test emails and notify a postgraduate student to review them.

2. The trigger: A new Gmail message matching the search query subject:PS5-URGENT.

3. The tools: Gmail New Email Matching Search (trigger) and Gmail Send Email (action).

4. It must never: Send notifications to anyone else; the Gmail Send Email To field is fixed to my personal test account. It must not automatically reply to, forward, or delete messages.

5. Where a person checks: The student reviews each alert and its original message in Gmail after delivery.

MGMT 6110 · Problem Set 5 · Analysis

Where the human stays in the loop

Q1. Map placement and justification

(a) My quadrant: AI alone, with checks (bottom left). School Mail Sentinel uses a Gmail search trigger to detect incoming messages whose subjects match subject:PS5-URGENT, then sends a notification to my personal test inbox.

(b) The map's two questions. The task has a verifiable right answer: the email either matches the search condition or it does not. Either a person or an automated workflow can perform this screening task alone. My live tests recorded three successful initial runs, and the post-fix run successfully included the original email subject in the alert. The body-only tricky case did not create a new Zap History run during my observation period, consistent with the subject-based search condition.

(c) The person in the loop. The agent may detect matching messages and send alerts automatically. I remain responsible for opening the original email, checking its context and deciding what action to take. The agent must not reply to, forward or delete messages. If it began interpreting ambiguous requests or recommending actions that require judgement, I would reconsider its placement because human judgement would become more central.

(d) My group's view. I agree with the group's bottom-left placement for the school email alert task: it has a clear matching rule and can be automated. However, automation does not remove human accountability. The person still reviews the original email, and the run history provides evidence for spot-checking. The task's placement describes the screening work, not the entire process of deciding how to respond to a school email.

Human–AI collaboration log

  • Delegated to AI: I used ChatGPT to plan the two-step workflow, draft the Agent Card, explain the Gmail search trigger, and prepare the analysis and test plan.
  • What I checked: I configured the Zap myself, reviewed the trigger and action test results, checked the successful Zap History records, and inspected the delivered alert emails.
  • Issue identified and corrected: The initial notification body was generic and did not identify the triggering email. I mapped the Gmail trigger's dynamic Subject field into the body, published a new version, and verified that the alert displayed “PS5-URGENT Fix Verification E”.
  • AI error caught: An AI-assisted description blurred the distinction between the map's Run Zap buttons and the actual Gmail workflow. I checked the code and found that ZAPIER_HOOK_URL was empty, so I corrected the page copy and kept the Catch Hook map controls distinct from the Gmail-based agent.
  • Tricky case: I sent a message with “Weekly Lecture Notes” as the subject and “PS5-URGENT” in the body. No new run appeared during my observation period. This was consistent with the subject-only search rule; it is evidence from this test, not a guarantee that every possible edge case is handled.
  • Time and cost: I worked on setup, testing, and documentation during the 20 October assignment session; exact focused minutes were not separately tracked. Zapier displayed a seven-day Professional trial notice and the dashboard showed task usage, so I cannot confirm that the account met the Free-plan requirement throughout the work.

Three-sentence reflection

School Mail Sentinel fits “AI alone, with checks” because its email-matching task has a clear rule and can run without a person handling each message. Its main limitation is that a successful notification does not determine the importance of the email or decide what the student should do, and the initial generic message also lacked useful context. I improved the workflow by adding the original email subject to the alert, and I would next test more edge cases and verify the plan's eligibility before relying on it for ongoing use.
